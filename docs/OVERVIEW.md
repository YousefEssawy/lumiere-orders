# نظرة عامة — Lumière Orders

## المشكلة اللي بيحلها

إدارة أوردرات Lumière كانت فيها خطوات مانيوال كتير ومبعثرة:
- أوردرات بتيجي من 3 مصادر: موقع **سلر**، **واتساب**، **إنستجرام**.
- كل أوردر لازم يتحوّل يدوياً لصيغة شركة الشحن **وصلها** (أسماء محافظات مختلفة، صيغة تليفون مختلفة، قواعد ثابتة للوزن والمرجع).
- مفيش مكان واحد يجمع كل الأوردرات أو يبقى سجل للعملاء.

## الحل

نظام واحد بيعمل:
1. **يجمع** كل الأوردرات في مكان واحد — استيراد ملف Export من سلر، وفورم يدوي للواتساب/إنستجرام.
2. **يحوّل** أوتوماتيك لصيغة وصلها (محافظات، أرقام، قواعد ثابتة).
3. **يصدّر** ملف Excel واحد جاهز للرفع على وصلها مرة واحدة.
4. **يحفظ** كل الأوردرات كسجل متزامن على السحابة، يتفتح من أي جهاز بعد لوجن.

## التدفّق (Flow)

```
┌─────────────┐     ┌──────────────┐
│ Export سلر  │────▶│              │

│ فورم يدوي   │────▶│  (Firestore) │     │ رفعة واحدة       │
│ واتس/إنستا  │     │              │     └──────────────────┘
└─────────────┘     └──────────────┘
```
